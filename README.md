# 🚕 NYC Taxi Analytics & Spark Performance Optimization

An end-to-end **Apache Spark analytics project** built using **PySpark on Databricks** with the NYC Yellow Taxi Trip dataset.

This project covers the complete analytical workflow — from raw data loading and data quality validation to data enrichment, business analysis, and Spark performance optimization.

The project focuses on practical **Spark DataFrame operations, Spark SQL, joins, aggregations, shuffle analysis, physical execution plans, Photon, and Adaptive Query Execution (AQE)**.

---

## 📌 Project Overview

The objective of this project is to analyze millions of NYC taxi trips while understanding both:

- **What the data tells us from a business perspective**
